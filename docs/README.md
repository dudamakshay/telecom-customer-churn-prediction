## 🔍 Key Metrics Reference

### **Business Impact**
- Churn Rate: **26.5%**
- Monthly Revenue at Risk: **$139,131**
- Annual Revenue at Risk: **$1,669,572**
- Model Accuracy: **81.76%**
- ROC-AUC Score: **0.85**

### **Top Churn Drivers**
1. Contract Type (Month-to-month: 42.7% churn)
2. Internet Service (Fiber optic: 41.9% churn)
3. Payment Method (Electronic check: 45.3% churn)
4. Customer Tenure (New: 53.3% churn)
5. Tech Support Adoption
